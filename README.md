# FRAGRANCE LUXURY — витрина парфюмерного магазина (Django)

Сайт только для просмотра ассортимента: без корзины, заказов, оплаты и контактов.
Посетитель смотрит каталог и приходит за покупкой в физический магазин.

## 1. Установка

```bash
cd perfume_store
python -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

## 2. Миграции базы данных

```bash
python manage.py makemigrations
python manage.py migrate
```

## 3. Наполнение каталога товарами

В файле `shop/management/commands/seed_products.py` уже прописан ваш реальный
список из 27 ароматов (названия и цены). Чтобы добавить их в базу:

```bash
python manage.py seed_products
```

Если вы **до этого** уже выполняли `seed_products` со старыми демо-товарами
(Dior Sauvage, Bleu de Chanel, Tom Ford Oud Wood, Black Opium) — они останутся
в базе и их нужно удалить вручную: зайдите в `/admin/` → «Парфюмы», отметьте
эти 4 товара галочками слева и удалите через действие «Delete selected Парфюмы».

Если позже понадобится изменить список или добавить ещё товары — отредактируйте
этот же файл (список `PRODUCTS`) и снова выполните команду; либо добавляйте
товары вручную через `/admin/`.

## 4. Создание администратора

```bash
python manage.py createsuperuser
```
Введите логин, email (можно пропустить) и пароль.

## 5. Запуск сайта

```bash
python manage.py runserver
```

Сайт: http://127.0.0.1:8000/
Каталог: http://127.0.0.1:8000/catalog/
Админка: http://127.0.0.1:8000/admin/

## 6. Как добавлять и менять фотографии парфюмов через Admin

1. Откройте http://127.0.0.1:8000/admin/ и войдите под своим логином/паролем.
2. Перейдите в раздел **Парфюмы**.
3. Найдите нужный товар (есть поиск по названию/бренду и фильтры).
4. Нажмите на него, чтобы открыть карточку редактирования.
5. В поле **Фотография** нажмите «Выбрать файл» и загрузите изображение.
6. Нажмите **Сохранить**.

После сохранения фотография сразу появится:
- в каталоге (`/catalog/`);
- на главной странице (если товар туда попадает);
- на странице самого товара (`/product/<id>/`).

Чтобы **заменить** фото — откройте товар, загрузите новый файл вместо старого, сохраните.
Чтобы **удалить** фото — откройте товар, поставьте галочку «Очистить» рядом с текущим изображением, сохраните.

Пока фото не загружено, на сайте автоматически показывается аккуратная заглушка «Фото скоро появится» — никакого пустого места или чужих картинок.

## Что сайт НЕ делает (намеренно)

Нет корзины, заказов, онлайн-оплаты, доставки, регистрации, личных кабинетов,
телефонов, адреса, карты, соцсетей и формы обратной связи — сайт информационный.
